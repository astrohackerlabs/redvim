RedVim modifications, 2026, Astrohacker contributors:
- Expose comment, comparison/shift operator and template delimiter nodes.
- Correct comment skipping during template classification and nested-comment
  scanning, with regression tests.
- Adapt highlight queries to target names and tokens independently, avoiding
  whole-declaration and whole-expression overcaptures.
- Add Rust LanguageFn/cc bindings, CommonJS generation metadata and tests.
- Generate the parser and headers with tree-sitter-cli 0.25.8 (ABI 15).

Unmodified upstream inputs are retained in crates/tree-sitter-wgsl/upstream.
Tree-sitter generator and generated support headers use the MIT notice in
tree-sitter-generator.txt. Exact input and output hashes are recorded in
docs/languages-provenance.json.
