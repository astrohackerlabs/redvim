# RedVim changelog

## [0.7.1]

### Maintenance

- Publish the pinned RedVim source as version 0.7.1, retaining bundled Nushell support.

## [0.7.0]

### Features

- First Astrohacker RedVim release, based on Red 0.7.0.
- Built-in Nushell parsing and highlighting; no grammar installation or trust step.
- Independent `redvim` command and configuration directory.

Upstream history and attribution remain in CHANGELOG.md and LICENSE.
